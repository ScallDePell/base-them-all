# Base Them'All

Système de jeu vierge pour Foundry VTT v14.

## Installation

Copier ce dépôt dans `Data/systems/base-them-all/` (le nom du dossier doit être identique à l'`id` du manifeste), puis créer un monde avec le système « Base Them'All ».

Le seul fichier requis par Foundry est `system.json`. Aucun type de document, script, style ni paramètre n'est déclaré.
